## Текущий результат

**Рабочий локальный адаптивный демо-эталон готов и прошёл приёмку.**
Это не готовый сайт реального бизнеса: условные данные и отключённая отправка согласованы и обозначены в интерфейсе.

Исходники:
- `template/index.html` — структура, тексты, демонстрационный каталог.
- `template/styles.css` — оформление и адаптация.
- `template/app.js` — поведение, словари моделей, подбор и диалоги.
- `template/assets/` — локальные JPG, исходные PNG, шрифты, библиотечные SVG и лицензии.
- `scripts/build-reference.js` — изолированная сборка.
- `dist/motodrive54/` — собранный эталон.

Стек: статический HTML/CSS/vanilla JavaScript, без фреймворка, установки npm-зависимостей и CDN.
Шрифты: локальный Roboto Condensed normal/italic. Иконки: Tabler и MDI ATV.
Все шесть иллюстраций сгенерированы встроенным image_gen; происхождение и промпты в `template/assets/ASSETS.md` и связанных markdown-файлах.
Для сайта используются облегчённые JPEG, исходные PNG сохранены.

## Запуск

Из корня проекта в PowerShell:

```powershell
npm.cmd run build:reference
npm.cmd run dev
```

Открыть: http://127.0.0.1:3000/dist/motodrive54/

При занятом порте сначала выяснить, не работает ли уже сервер. В предыдущей сессии сервер был запущен; его дальнейшая жизнь не гарантируется.
Другой порт: `npm.cmd run dev -- --port 3001`.
В среде Codex сетевые ограничения иногда требуют разрешённого запуска сервера вне песочницы; ранее это решалось запуском `node scripts/serve.js --port 3000` через стандартное разрешение инструмента.
Не устанавливать зависимости или другой сервер без необходимости.

## Что нельзя потерять или случайно запустить

- Не перезаписывать исходники старым генератором.
- Использовать **только build:reference** для текущего эталона.
- `npm run build` и `npm run all` защищены ранним отказом по маркеру reference-template.
- `npm run generate` и `npm run dossiers` ПО ОТДЕЛЬНОСТИ остаются старыми и могут перезаписывать заготовки. Их не запускать для эталона.
- Старый генератор контента сочинял отзывы, цены и наличие. JSON, старые досье и рейтинги не являются источниками фактов.
- `verified_leads/` содержит отдельный прежний отчёт с общими обозначениями источников. В этой задаче его сведения не перепроверялись; слово verified в имени файла не заменяет независимые доказательства.
- Другие 18 демо не пересобирались и не прошли эту приёмку.
- Не подключать старые телефоны, адреса, WhatsApp или отзывы из заготовок.
- Не обещать отправку заявок: сейчас есть только локальный черновик. Контакты и получатель не подключены.
- Не публиковать и не отправлять сообщения без соответствующего задания Максима.
- Не копировать UI целиком в одну картинку: сайт уже свёрстан редактируемыми элементами.
