# Рабочий демо-эталон МотоДрайв 54

Основа: выбранный макет `макеты_эталона/06_гибрид_01_04.png`.
Это локальный адаптивный демо-сайт с согласованными условными данными.

## Открыть

При работающем сервере: http://127.0.0.1:3000/dist/motodrive54/

Запуск из папки проекта в Windows:

```powershell
npm.cmd run build:reference
npm.cmd run dev
```

Node.js уже используется в этом проекте. Установка npm-зависимостей для эталона не нужна.
Если порт занят, можно запустить `npm.cmd run dev -- --port 3001` и открыть тот же путь на порту 3001.

## Где менять

- `template/index.html` — структура и видимый текст.
- `template/styles.css` — оформление и адаптивность.
- `template/app.js` — фильтры, карточки, подбор, диалоги и копирование черновика.
- `template/assets/` — локальные изображения, шрифты, иконки и их происхождение.
- `dist/motodrive54/` — результат изолированной сборки.

После изменений выполняй только `npm.cmd run build:reference`, затем обновляй страницу.
Старые массовые `build` и `all` защищены от запуска на новом эталоне. Старый генератор
контента по отдельной команде `generate` остаётся прежним: для этого эталона он не нужен.

## Что работает

Навигация, мобильное меню, фильтры каталога и пустая категория экипировки,
окна товаров с характеристиками, сценарии подбора, составление и копирование
черновика запроса с проверкой роста, сервисные и контактные диалоги.
При отсутствии фотографий показаны подписи вместо сломанных изображений.

## Что остаётся демонстрационным

МотоДрайв 54 здесь — вымышленный концепт. Модели, цены, характеристики и изображения
условные. Телефон, адрес, график и получатель заявок не подключены. Сайт не отправляет
сообщения и не подтверждает запись. Эти ограничения явно видны в интерфейсе.

Перед реальным запуском нужно заменить условные сведения проверенными данными бизнеса,
подключить контакты и при необходимости доставку заявок, проверить её и только затем публиковать.
