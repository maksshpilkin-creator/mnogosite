# Иллюстрации эталонного демо

Все изображения созданы встроенным image_gen специально для согласованного вымышленного демо «МотоДрайв 54». Они не являются реальными фотографиями салона и не подтверждают его ассортимент или услуги.

| Файл для сайта | Назначение | Исходник |
|---|---|---|
| hero-enduro.jpg | Светлый студийный hero | hero-enduro.png |
| product-enduro.jpg | Карточка эндуро | product-enduro.png |
| product-pitbike.jpg | Карточка питбайка | product-pitbike.png |
| product-atv.jpg | Карточка квадроцикла | product-atv.png |
| rider.jpg | Блок подбора техники | rider.png |
| showroom.jpg | Иллюстративный шоурум | showroom.png |

JPEG-копии созданы из исходных PNG с качеством 88 для уменьшения веса без изменения композиции. Общий вес используемых изображений — около 1,6 МБ. Исходники сохранены.

Промпты: [hero-prompt.md](hero-prompt.md), [product-prompts.md](product-prompts.md), [support-prompts.md](support-prompts.md).

Шрифты и иконки имеют отдельные файлы лицензий в подкаталогах fonts и icons.
