- `template/assets/fonts/` — локальные Roboto Condensed Variable normal/italic, SIL OFL.

- `scripts/build.js` — ранний guard по reference-template перед любыми mkdir/write; предлагает build:reference.
- `scripts/serve.js` — корректные MIME, настраиваемый port/host, redirects для корня/директорий, проверка границ пути и блокировка скрытых директорий.
- `package.json` — команды build:reference и dev.
- `dist/motodrive54/` — локальная сборка.
- Резервные копии старых template/index.html, scripts/build.js, scripts/serve.js, package.json: `reports/backups/reference-before-20261108-152837/`.

Остальные content и dist-страницы не изменялись. Старые generate/all/build не запускались.

## Интерфейс

Категории и sidebar фильтруют три модели; экипировка показывает честный empty-state. Карточки открывают нативный dialog с изображением, характеристиками и ценой. Chips подбора обновляют пояснение и сценарий черновика. Черновик позволяет выбрать модель, указать рост и опыт; поле роста имеет inline validation. Copy вызывает реальный Clipboard API и подтверждает только успешную запись; при отказе/недоступности выделяет текст для ручного копирования. Заявок и фиктивного уведомления об отправке нет.

Контактные кнопки открывают окно «Контакты подключим после уточнения». Service controls показывают разумное описание сценария, не обещая наличие или запись. Меню мобильное; dialog поддерживает закрытие кнопкой, Escape и backdrop, блокирует прокрутку и возвращает фокус. При ошибке изображения показана честная подпись; системный шрифт служит fallback для локального шрифта.
