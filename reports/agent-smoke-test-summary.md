# Короткая проверка агентов — 08.11.2026

Задача Максима: проверить работоспособность с небольшим расходом, без запуска
исследования всех бизнесов. Использован руководитель GPT-6 Luna с low;
сохранённые роли запускались со своими настроенными моделями и high.
Рабочая папка агентов была в режиме read-only. Браузер, веб, публикация,
сообщения клиентам, сборка и исправление сайтов в тест не входили.

## Результат

|---|---|---|

Все пять сохранённых agent types фактически вызывались. Тест подтверждает запуск
и поведение на указанных случаях; не подтверждает качество полного рабочего конвейера.
Ответы первых четырёх приведены в отчёте руководителя, не в отдельном независимом
журнале каждого субагента. Результат проверяющего сопоставлен с HTML дополнительно:
несовпадение действительно есть на строках 153/154, 210, 651 и 707.

## Что пришлось исправить в методе проверки

1. Первый временный CLI-запуск не смог породить роли с наследованием истории:
   `failed to load model context ... no rollout found`. Ни одна роль в той попытке
   не выполнила задание. После `fork_turns="none"` / `fork_context=false` запуск прошёл.
2. В общей попытке проверяющий не выполнил сравнение, поскольку поручение
   ограничило его чтение инструкциями. Повторно вызвана только эта роль с явным
   разрешением читать назначенный HTML. Уточнена формулировка общего AGENTS.md:
   отдельно указывать разрешения чтения и записи.

Сами TOML-определения ролей менять не потребовалось. Массовый рабочий запуск
не выполнялся. Проверяемые сайты, CSV, content и генераторы не изменялись.

## Артефакты

- `agent-smoke-test-result.md`, `agent-smoke-test-events.jsonl`,
  `agent-smoke-test-stderr.log` — первая неудачная попытка, не итог проверки.
- `agent-smoke-test-retry-result.md`, `agent-smoke-test-retry-events.jsonl` —
  запуск всех ролей; содержит первоначально неполный результат проверяющего.
- `agent-smoke-test-verifier-result.md`, `agent-smoke-test-verifier-events.jsonl` —
  успешная целевая повторная проверка.
- `agent-smoke-test-prompt.txt`, `agent-verifier-smoke-prompt.txt` — поручения.
- `run-agent-smoke-test.cjs` — воспроизводимый тестовый запуск; самостоятельно
  не запускается. Повторный запуск использует модели и расходует лимит.

Точная стоимость в кредитах не доступна в результатах CLI. В JSONL сохранены
показатели usage тестовых руководителей; полный учёт расходов субагентов
отдельно не подтверждён. Оценка денежной стоимости не выполнялась.
